# @thevue/btn

> Btn component for the thevue framework.

## Install

```bash
npm install @thevue/core @thevue/btn
```

```ts
import '@thevue/btn/style'
```

## Usage

```vue
<script setup lang="ts">
import { Btn } from '@thevue/btn'
</script>

<template>
  <Btn>content</Btn>
</template>
```
